# Resume Analyzer System

A JavaFX-based desktop application that analyzes resumes, extracts skills, calculates match score, and provides suggestions.

## 🚀 Features

* Upload Resume (PDF)
* Extract Text using Apache PDFBox
* Skill Extraction
* Match Score Calculation
* Suggestions for missing skills
* SQLite Database storage

## 🛠 Tech Stack

* Java
* JavaFX
* Apache PDFBox
* SQLite
* Maven

## ⚙️ How to Run

1. Clone the repository
2. Open in IntelliJ IDEA
3. Run MainUI.java
4. Upload resume and see analysis

## 📊 Output

* Resume text display
* Match score (%)
* Extracted skills
* Suggestions
